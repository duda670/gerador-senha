# Gerador de Senhas em Python

Gerador de senhas seguras para o terminal.

## Como usar

1. Instale o Python 3
2. Rode no terminal: `python gerador_senha.py`

## O que ele faz

- Gera senhas com o tamanho escolhido
- Permite incluir maiúsculas, números e símbolos
- Garante pelo menos um caractere de cada tipo selecionado
- Usa o módulo `secrets`, próprio para senhas

## Tecnologias

- Python
